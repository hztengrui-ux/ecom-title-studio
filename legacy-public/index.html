        QUICK GUIDE
        
怎么用

      

      
    

    

      
    
        
  1. 01
    选一张商品图
    主体占画面 1/3 以上，背景干净。支持拖拽、点击与 Ctrl+V 粘贴。
    2. 
        
  2. 02
    补三行信息（可选）
    品类、卖点、人群越具体，标题越不容易写成空话。品牌留空时不会虚构品牌。
    3. 
        
  3. 03
    选平台与策略
    最多同时生成六个平台。策略最多选三个，默认覆盖流量、转化与长尾。
    4. 
        
  4. 04
    复制前先核对
    字数、极限词与图片信息都已检查，但材质、成分、认证仍需与实物一致。
    5. 
      


      

        

          
平台建议上限写法

          
            
淘宝 / 天猫30 字核心词前置，属性 + 场景

            
拼多多30 字利益点直给，少形容词

            
抖店30 字画面感、口语化、人群词

            
京东30 字规格、材质、型号优先

            
TEMU120 字符自然英文，关键词 + 场景

            
Amazon200 字符核心词 + 属性 + 使用场景

          
        

        
平台规则会调整，以上为常用建议上限；上架前以商家后台提示为准。
